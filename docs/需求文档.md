### 使用说明

本文档用于直接交给 AI 编程工具或开发者实现产品。实现时以“功能需求”和“验收标准”为准，重点还原用户可以看到、点击和完成的操作，不需要根据本文档设计复杂的数据架构。

- 先完成可以运行的桌面应用和核心操作闭环，再处理视觉细节。
- 每实现一个模块，使用对应验收标准验证实际行为。
- 未明确规定的技术细节由实现者选择简单、稳定、便于维护的方案。
- AI 接口暂时不可用时，可以保留接口适配层，但不能用假成功状态替代真实错误提示。
- 所有按钮、菜单和弹窗都必须有实际交互，不能只制作静态页面。

## 2. 产品概述

AI设计助手是一款面向个人设计师、内容创作者和电商运营人员的桌面端 AI 图片创作工具。用户可以建立多个无限画布，通过文生图、图生图或本地上传的方式添加图片，在画布中自由组织素材，并对图片进行基础调整、AI 编辑和版本管理。

产品以“画布”为项目容器，以“图片”为核心创作元素，通过本地 SQLite 保存画布、图片、提示词、模型配置、空间位置和历史版本，使用户可以持续进行视觉探索，而不必在多个生成网站和本地文件夹之间切换。

## 3. 产品目标

### 3.1 核心目标

1. 让用户在一个工作区内完成图片生成、整理、编辑和版本选择。
2. 使用无限画布承载视觉探索过程，降低素材管理成本。
3. 支持 OpenAI 兼容图片接口，允许用户配置自己的模型服务。
4. 将创作数据保存在本地，保证重新打开应用后可以继续工作。

### 3.2 非目标

V1.0 暂不包含以下能力：

- 多用户实时协作。
- 云端作品同步和跨设备同步。
- PSD、Sketch、Figma 等专业设计文件导入与导出。
- 复杂图层、矢量路径、蒙版和文字排版工具。
- 模型服务的账号充值、计费和额度管理。

## 4. 目标用户

### 4.1 个人设计师

需要快速生成视觉方案，在同一画布中比较多个方向，并保留历史版本。

### 4.2 内容创作者

需要为文章、短视频和社交媒体快速生成、调整和导出配图。

### 4.3 电商运营人员

需要生成商品场景图、宣传素材和不同风格的视觉版本。

### 4.4 AI 图片爱好者

拥有自己的图片模型 API，希望使用统一的桌面工具管理提示词和生成结果。

## 5. 核心使用场景

1. 用户为一个设计任务创建独立画布，并录入画布名称。
2. 用户在画布中通过提示词生成第一张图片。
3. 用户上传本地参考图，并将图片放置在画布中。
4. 用户对某张图片执行图生图，产生多个历史版本。
5. 用户在左侧图片列表中选择作品，画布自动将该图片移动到视口中央。
6. 用户在画布中调整图片位置、缩放视图并比较多个方案。
7. 用户选择满意的版本，将图片导出到本地目录。

## 7. 功能需求

### 7.1 画布管理

#### FR-CANVAS-001 画布列表

- 左侧区域展示全部无限画布。
- 每个画布展示名称、作品数量、最近更新时间和封面缩略图。
- 画布有图片时，默认使用该画布的第一张图片作为封面。
- 当前打开的画布需要有明确的选中状态。

#### FR-CANVAS-002 新建画布

- 用户点击“新建”后显示浮层表单。
- 表单包含必填的画布名称。
- 系统可提供默认名称，用户可以修改。
- 创建成功后自动进入新画布。
- 空名称不得提交。

#### FR-CANVAS-003 打开画布

- 用户点击画布卡片即可打开画布。
- 不要求用户点击单独的上下箭头。
- 打开后加载该画布的全部图片和已保存坐标。

#### FR-CANVAS-004 展开图片列表

- 画布卡片提供展开、收起状态提示。
- 展开后，在卡片下方显示该画布中的全部图片元素。
- 每个图片元素至少展示缩略图和提示词或文件名。

#### FR-CANVAS-005 画布右键菜单

- 用户右键画布卡片时显示操作菜单。
- 菜单包含“修改画布名称”“新建图片”“上传图片”。
- 点击菜单外区域或按 Esc 后关闭菜单。

#### FR-CANVAS-006 修改画布名称

- 选择“修改画布名称”后显示名称编辑浮层。
- 输入框默认填充当前名称。
- 保存后同步更新左侧列表和主区域标题。

### 7.2 无限画布

#### FR-BOARD-001 画布视图

- 主区域采用可无限平移和缩放的点阵画布。
- 图片使用独立节点展示，并保留图片的原始宽高比例。
- 图片节点下方展示提示词或来源文件名。

#### FR-BOARD-002 平移与缩放

- 用户可以使用滚轮或触控板平移画布。
- 用户可以使用组合键加滚轮或工具栏控制缩放。
- 提供选择工具和抓手工具。
- 提供“适配全部内容”能力。

#### FR-BOARD-003 选择图片

- 点击图片节点后选中该图片。
- 选中节点需要显示高亮边框。
- 支持在空白区域框选多个图片节点。
- 点击空白区域或按 Esc 可以取消选择。

#### FR-BOARD-004 移动图片

- 用户可以在画布中自由拖动图片节点。
- 移动过程中实时更新节点位置。
- 拖动结束后将坐标保存到本地数据库。
- 重新打开画布后恢复上次位置。

#### FR-BOARD-005 列表图片定位

- 用户点击画布列表中的图片元素后，系统选中对应图片。
- 如果图片属于其他画布，系统先打开目标画布。
- 系统自动平移画布，使目标图片显示在视口中央。
- 居中时保持当前缩放比例，不应突然放大或缩小。
- 居中只触发一次，不影响用户后续拖动图片。

### 7.3 图片管理

#### FR-ASSET-001 上传图片

- 用户可以从画布右键菜单或空画布引导区域上传图片。
- 支持系统能够展示的常见图片格式。
- 单张图片大小上限为 20 MB。
- 上传成功后将图片添加到目标画布并保存到数据库。
- 图片提示信息默认使用原文件名。

#### FR-ASSET-002 图片右键菜单

- 用户右键图片节点时显示操作菜单。
- 菜单包含“编辑”和“删除”。
- 打开菜单的同时选中目标图片。

#### FR-ASSET-003 删除图片

- 用户点击删除后必须显示确认对话框。
- 对话框说明图片及其历史版本将被永久删除。
- 用户确认后删除图片和所有关联版本。
- 删除完成后同步更新画布、作品数量、封面和图片列表。
- 用户取消时不得修改数据。

#### FR-ASSET-004 导出图片

- 用户可以将当前图片或编辑结果保存到本地。
- 保存前显示系统文件保存对话框。
- 支持 PNG、JPEG 和 WebP 等常用格式，具体格式由图片数据和文件扩展名决定。

### 7.4 AI 图片生成

#### FR-AI-001 文生图

- 用户可以从指定画布中发起“新建图片”。
- 表单包含提示词、模型、尺寸和质量。
- 提示词和模型为必填项。
- 生成期间显示加载状态并防止重复提交。
- 生成成功后自动保存图片并添加到目标画布。

#### FR-AI-002 图生图

- 用户在图片编辑器中以当前选中版本作为参考图。
- 用户输入新的编辑提示词并选择图生图模型。
- 系统通过兼容 `/images/edits` 的接口提交图片和参数。
- 生成结果作为新版本保存，不覆盖原始版本。

#### FR-AI-003 请求参数

- 支持正方形、横向和纵向尺寸。
- 支持低、中、高三档生成质量。
- 文生图采用 JSON 请求。
- 图生图采用 `multipart/form-data` 请求，并通过 `image[]` 传递参考图。
- 单次请求最长等待时间为 10 分钟。

#### FR-AI-004 异常处理

- API Key 缺失、接口不可达、鉴权失败或模型返回异常时，向用户显示可理解的错误信息。
- 失败请求不得创建空图片记录。
- 远程接口返回图片 URL 时，主进程负责下载并转换为本地可持久化数据。

### 7.5 图片编辑

#### FR-EDIT-001 基础调整

- 支持亮度调整。
- 支持对比度调整。
- 支持饱和度调整。
- 支持旋转。
- 支持水平翻转和垂直翻转。
- 调整结果需要在编辑器中实时预览。

#### FR-EDIT-002 原分辨率处理

- 编辑和导出时以图片原始分辨率渲染。
- 预览区域缩放不得降低最终导出质量。

### 7.6 图片版本管理

#### FR-VERSION-001 初始版本

- 新增图片时自动创建 V1。
- V1 保存原始图片数据、提示词和创建时间。

#### FR-VERSION-002 新版本

- 每次图生图成功后创建递增版本，如 V2、V3。
- 新版本记录来源图片、提示词、创建时间和版本号。
- 创建新版本后不删除旧版本。

#### FR-VERSION-003 版本选择与应用

- 编辑器展示当前图片的全部版本。
- 用户可以预览和选择任意版本。
- 当前使用版本需要有明确状态。
- 用户应用版本后，画布节点、列表缩略图和画布封面需要同步更新。

### 7.7 模型配置

#### FR-MODEL-001 模型类型

- 支持一套文生图模型配置。
- 支持一套图生图模型配置。
- 两种任务类型的模型独立保存和使用。

#### FR-MODEL-002 配置字段

每套模型包含：

- 配置名称。
- 服务提供方类型。
- API Base URL。
- API Key。
- 模型名称。
- 任务类型。

#### FR-MODEL-003 接口规范化

- 系统根据任务类型自动补全 `/images/generations` 或 `/images/edits`。
- 用户输入完整接口地址时，系统不得重复拼接路径。

#### FR-MODEL-004 连接测试

- 用户可以在保存前测试模型连接。
- 测试请求访问服务的模型列表接口，不发起付费图片生成。
- 测试结果展示连接状态、模型是否存在和响应耗时。
- 对鉴权失败、网络错误和连接超时提供不同提示。

### 7.8 本地数据存储

#### FR-DATA-001 持久化范围

系统需要保存：

- 画布名称、创建时间和更新时间。
- 图片内容、提示词和创建时间。
- 图片所在画布、坐标和显示宽度。
- 图片历史版本和当前版本。
- 模型名称、地址、密钥和任务类型。

#### FR-DATA-002 数据库

- 使用 SQLite 本地数据库。
- 数据库文件保存在 Electron 用户数据目录。
- 写入时先输出临时文件，再替换正式数据库文件，降低文件损坏风险。
- 数据表升级时兼容已有数据。

#### FR-DATA-003 安全边界

- 渲染进程不得直接访问 Node.js 和本地文件系统。
- API 请求、数据库访问和文件保存由 Electron 主进程执行。
- 前端仅能通过受控的 Preload API 调用主进程能力。

## 8. 关键业务流程


## 9. Vibe Coding 实现要求

### 9.1 页面布局

- 应用采用桌面端三段式结构：顶部应用栏、左侧画布列表、右侧无限画布工作区。
- 顶部应用栏显示“AI设计助手”和模型配置入口。
- 左侧栏宽度保持稳定，顶部显示画布数量和新建按钮，下方为可滚动的画布列表。
- 右侧工作区占据剩余空间，画布始终铺满可用区域。
- 图片编辑器、名称输入和删除确认使用浮层或弹窗，不跳转到新页面。

### 9.2 建议组件拆分

- 应用外壳：负责顶部栏、左侧栏、当前画布和全局弹窗。
- 画布列表：负责画布卡片、展开状态和图片子列表。
- 无限画布：负责缩放、平移、选择、拖动和图片定位。
- 图片生成弹窗：负责提示词、模型、尺寸和质量。
- 图片编辑器：负责基础调整、图生图和版本选择。
- 模型配置弹窗：负责两种模型配置和连接测试。
- 通用确认弹窗：负责删除等危险操作。

组件可以按实际框架调整，但不同业务区域不应全部堆叠在一个页面文件中。

### 9.3 状态与反馈

- 新建、生成、上传、保存和删除操作需要显示进行中状态。
- 操作进行中时禁用会造成重复请求的按钮。
- 成功操作使用短暂提示反馈；失败操作显示用户可以理解的原因。
- 空画布、无模型配置、图片加载中和接口失败都需要独立状态。
- 应用重新启动后，用户创建的画布、图片、位置和版本应继续存在。

### 9.4 交互一致性

- 画布卡片左键用于打开并切换展开状态，右键用于显示画布操作菜单。
- 图片列表项左键用于选中并居中图片。
- 画布中的图片左键用于选择和拖动，右键用于显示图片操作菜单，双击用于编辑。
- 点击菜单外区域或按 Esc 关闭当前菜单。
- 所有删除行为先确认，所有取消操作不得产生数据变化。

### 9.5 开发顺序

建议按照以下顺序完成，确保每一步都有可运行结果：

1. 搭建桌面应用外壳和三段式布局。
2. 实现画布列表、新建、重命名和切换。
3. 实现图片上传、画布展示、拖动、缩放和平移。
4. 实现图片右键菜单、编辑和删除确认。
5. 实现模型配置、连接测试和文生图。
6. 实现图生图、版本列表和版本应用。
7. 补充本地持久化、异常状态和构建验证。

### 9.6 完成定义

- 项目可以通过文档中的运行命令启动。
- 页面不是静态原型，核心按钮和菜单均能完成对应操作。
- 刷新或重启应用不会丢失已保存内容。
- 核心流程没有阻断性错误，控制台没有持续报错。
- 第 11 节中的验收项全部通过后，才视为 V1.0 实现完成。

## 10. 非功能需求

### 10.1 性能

- 普通规模画布打开后应在 2 秒内展示本地内容。
- 拖动画布和图片时保持连续、无明显卡顿。
- 图片生成期间不得阻塞画布浏览和基础交互。
- 大图应避免不必要的重复 Base64 转换和 React 重渲染。

### 10.2 稳定性

- 数据写入失败时显示错误提示，不得伪装为保存成功。
- API 请求失败后允许用户重试。
- 应用异常关闭后，已经完成保存的数据可以恢复。

### 10.3 安全性

- 启用 Electron `contextIsolation`。
- 禁止渲染进程使用 Node.js 集成。
- API Key 不写入日志，不在错误提示中完整显示。
- 外部接口响应作为不可信数据处理。

### 10.4 易用性

- 所有破坏性操作必须二次确认。
- 加载、成功和失败状态必须有明确反馈。
- 右键菜单、弹窗和编辑器支持 Esc 关闭。
- 操作名称保持中文一致性。

### 10.5 兼容性

- 支持 macOS 和 Windows 桌面环境。
- 支持 OpenAI 图片接口或兼容其请求与响应结构的服务。

## 11. 验收标准

### 11.1 画布验收

- 可以连续创建多个不同名称的画布。
- 重启应用后画布列表和名称仍然存在。
- 点击画布卡片可以直接打开并展开或收起图片列表。
- 点击图片列表项后，对应图片位于画布视口中央。

### 11.2 图片验收

- 可以上传不超过 20 MB 的图片并显示在目标画布。
- 图片拖动后，切换画布再返回，位置保持不变。
